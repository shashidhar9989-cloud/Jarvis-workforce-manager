# JARVIS Workforce Manager V6

This repository is a standalone GitHub Pages/PWA version of the JARVIS Workforce Manager.

## Files
- `index.html` — app
- `manifest.json` — installable app information
- `sw.js` — offline/app-shell cache
- `icon-192.png`, `icon-512.png` — app icons

## GitHub Pages
Use **Settings → Pages → Deploy from a branch → main → / (root)**.

The Pages site must have `index.html` at the top level of the published folder.

## Install on iPhone
Open the GitHub Pages URL in Safari → Share → **Add to Home Screen**.
